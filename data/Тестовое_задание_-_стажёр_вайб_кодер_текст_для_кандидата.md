# Тестовое задание — стажёр / вайб-кодер (офис)

> Оцениваем не только финальный код, но и то, как ты читаешь чужой код, проверяешь результат и объясняешь решение.

---

## Формат

- Время на выполнение: 3–5 часов.
- Инструменты: любые, ИИ-ассистенты (Claude Code, Cursor, ChatGPT и т.п.) — можно и нужно использовать.
- Сдача: ссылка на git-репозиторий (GitHub/GitLab, публичный или с временным доступом) + короткий созвон (15–20 мин) для объяснения решения.

## Данные

Даём три артефакта:
1. Анонимизированную выгрузку отчёта по продажам с маркетплейса (Excel/CSV).
2. Второй файл — реестр заказов/отправлений (тот же период, немного другая структура) для сверки с первым.
3. Черновой скрипт (10–20 строк) в стиле быстрой автоматизации — без обработки ошибок, без логирования, с обращением к внешнему API без ретраев.

## Что нужно сделать

**Часть 1 — доработка готового скрипта.**
1. Взять черновой скрипт и довести до продакшн-уровня:
   - логирование вместо `print`;
   - обработка ошибок (битый файл, отсутствующая колонка, недоступный API);
   - ретраи с задержкой для обращения к внешнему API (можно замокать вызов, который иногда падает);
   - минимум 2–3 автотеста (pytest) на ключевую логику, включая граничные случаи.
2. Не переписывать всё с нуля — объясни, что оставил, что изменил и почему. Внимательно проверь, что скрипт действительно считает правильно — не только красиво выглядит.

**Часть 2 — сверка двух источников.**
3. Сопоставь выгрузку и реестр по общему ключу (номер заказа/отправления) и найди расхождения: что есть в одном файле, но нет в другом; где отличается сумма/количество.
4. Выведи результат структурированно: сколько совпало, сколько расхождений и в чём именно.

**Часть 3 — расчёт по выгрузке.**
5. Посчитай 2–3 показателя (выручка по товару, доля возвратов, топ-5 по обороту), выведи аккуратно.

**Часть 4 — git и объяснение.**
6. Git-репозиторий: минимум 4–5 осмысленных коммитов, интерфейс запуска через аргументы командной строки (не хардкод путей).
7. Коротко объясни (README или на созвоне):
   - как использовал ИИ-ассистента и что перепроверял вручную;
   - как бы вывел это в расписание (cron / schtasks) и что мониторил бы в проде.
